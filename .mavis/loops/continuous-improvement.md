# Continuous Improvement Loop

## Goal

Find one small, high-impact improvement and deliver it through branch, tests, report and PR.

## Rules

- One improvement per loop.
- No auto-merge.
- No push to main.
- Verify before claiming done.
- Update memory/RAG if architecture, DB, API, security or behavior changes.

## Output

- Patch
- Tests
- `.mavis/reports/latest-loop-report.md`
- Commit
- PR only with explicit permission
