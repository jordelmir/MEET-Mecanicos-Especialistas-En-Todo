# RAG Chunking Policy

## Truth Rule

RAG is derived. Git is truth.

## Code

Use symbol-aware chunking.

Include:

- file path
- language
- symbol name
- imports
- related tests

## Docs

Use heading-aware chunking.

## SQL

Use object-aware chunking:

- table
- policy
- function
- trigger
- migration

## Android

Use feature-aware chunking:

- ViewModel
- UiState
- UseCase
- Repository
- Composable

## Security

Never chunk secrets, credentials, keystores, production dumps, raw VIN/GPS logs or personal data.
