# Viajes V5 — Rating System

Estado: contrato objetivo; el rating local heredado no se considera autoridad.

`ride_ratings_v2` debe exigir viaje completado, participación real, unicidad por viaje/reviewer/reviewee, RPC idempotente y publicación ciega cuando ambos califican o vence la ventana. Calidad, trust signals y safety cases permanecen separados. La reputación visible usará promedio bayesiano y tamaño de muestra; acceptance y completion se calculan con denominadores elegibles reales.
