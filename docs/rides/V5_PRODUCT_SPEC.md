# Viajes V5 — Product Spec

Objetivo: movilidad basada en libertad de elección, precio explicable, seguridad bilateral y trazabilidad.

## Tarifas

El pasajero elige antes de solicitar:

- **Pon tu precio**: oferta negociable; las paradas se declaran antes de publicar y quedan bloqueadas durante el viaje.
- **Tiempo + distancia**: ₡300/km + ₡60/min; muestra estimado y desglose, permite cambiar paradas durante estados activos y recalcula el estimado.

El estimado no se presenta como total definitivo. La tarifa final medida solo puede proceder de evidencia autoritativa y liquidación de servidor.

## Experiencia objetivo

Map-first con bottom sheet progresivo: explorar, configurar, elegir modalidad, recibir ofertas, viaje activo y post-viaje. Guardian permanece a dos taps como máximo. Ninguna función futura se muestra como operativa hasta tener proveedor y autoridad reales.
