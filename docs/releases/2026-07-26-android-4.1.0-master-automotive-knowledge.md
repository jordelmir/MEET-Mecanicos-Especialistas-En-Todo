## Alcance

Esta entrega mantiene el Motor 3D 360° restaurado y añade una capa única,
determinista y citada para piezas, DTC, diagnóstico, reparación, IA y
navegación 3D.

Incluye:

- grafo de 5,446 nodos y 5,411 aristas compilado desde 74,648 bloques;
- repositorio Android fail-closed con hash fijado;
- aplicabilidad por vehículo y evidencia;
- secuencia P0230 circuito-primero;
- contexto IA allowlist sin VIN completo;
- publicación de repuestos bloqueada sin gate canónico exacto;
- navegación 3D procedural/genérica, nunca dimensional u OEM;
- paridad de compatibilidad y sugerencias entre TypeScript y Kotlin;
- política `EXACT` endurecida a VIN + OEM verificado o tupla cerrada con OEM.

## Autoridad y seguridad

- Un DTC es una pista, no una pieza condenada.
- Un alias, nombre o selección 3D no prueba aplicabilidad.
- `NOT_DOCUMENTED` no se muestra como ausencia demostrada.
- Datos simulados, manuales o sin enlace no abren compras.
- Un reporte firmado y sus contratos de hash no fueron modificados.
