# MEET 4.26.0 — Viajes, objetos olvidados y sincronización

Fecha: 2026-09-18. Android `versionCode 59`; web `4.26.0`.

## Alcance

- El pasajero informa un objeto desde un viaje confirmado. El mensaje conserva el `ride_request_id` y se sincroniza por `ride_messages`; la interfaz distingue guardado local de entrega remota.
- El chofer abre el centro de objetos olvidados desde Perfil → Soporte, ve cuáles viajes tienen reportes, accede al chat del viaje completado y llama si hay un número disponible.
- El chat histórico selecciona el viaje solicitado en lugar de reutilizar el viaje activo. Los controles estrechos usan espacio vertical o desplazamiento horizontal para evitar letras apiladas.
- Las preferencias de pasajero se muestran en tarjetas de despacho y viaje. La calificación asentada se recuerda localmente.
- El receptor de automatización de debug exige permiso de firma; el receptor sigue ausente de release.

## Datos y migraciones

- Supabase: `20260918173552_ride_chat_actor_role_guard.sql` vincula el rol declarado de cada mensaje con el pasajero o conductor real del viaje. `20260918174056_ride_chat_message_immutability.sql` impide reescribir mensajes ya creados. Las migraciones anteriores hasta `20260918020000` ya estaban aplicadas en el proyecto vinculado al inicio de esta entrega.
- Room: esquema 77. `RideChatMessageEntity`, `rideRequestId` y el DAO de chat existían; la consulta de reportes no altera columnas ni requiere migración Room nueva. Los mensajes pendientes se reintentan tras refrescar la proyección autenticada.
- La tarifa mostrada al usuario no constituye cálculo de distancia, débito, cobro ni recibo del servidor. El mensaje de objeto olvidado tampoco crea automáticamente un caso de soporte.

## Evidencia y límites

- `npm run check:versions`, pruebas web, compilación y APK Android, paridad y CI deben verificarse para el SHA final publicado.
- La instalación y apertura de este APK se comprobaron en Honor VER_N49 y Xiaomi M2101K6R. Esto no prueba el intercambio del reporte entre dos cuentas ni el diseño visual en todas las densidades.
- No se declara entrega a producción, lectura del chofer ni pago recibido sin acuse remoto y prueba de dos cuentas.
