# Security policy

Do not include report narratives, precise locations, victim identities, private
evidence, credentials or exploit payloads against third parties in public issues.
Coordinate private disclosure with the repository owner through the platform's
private vulnerability reporting facility when enabled. No invented contact
address is provided. Reproduce findings with synthetic fixtures in an owned lab.

Cryptographic protocol review and physical Mesh verification are mandatory
before production claims. A hash proves integrity relative to bytes, not truth
of an allegation, criminal guilt or authenticity of a source.
